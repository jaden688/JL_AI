Install in 30 seconds

Add to ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) or %APPDATA%\Claude\claude_desktop_config.json (Windows):

{
  "mcpServers": {
    "sparkbyte": {
      "command": "python",
      "args": ["-m", "sparkbyte_mcp"],
      "env": { "SPARKBYTE_LICENSE": "your-license-key-here" }
    }
  }
}

Restart Claude Desktop. SparkByte tools appear in the tool picker.

Open Cursor → Settings → MCP → Add new MCP server:

Name:    sparkbyte
Type:    command
Command: python -m sparkbyte_mcp
Env:     SPARKBYTE_LICENSE=your-license-key-here

Enable the server. Tools available in agent mode.

Add to .vscode/mcp.json in your workspace (or user settings):

{
  "servers": {
    "sparkbyte": {
      "type": "stdio",
      "command": "python",
      "args": ["-m", "sparkbyte_mcp"],
      "env": { "SPARKBYTE_LICENSE": "your-license-key-here" }
    }
  }
}

GitHub Copilot Chat picks it up automatically.
